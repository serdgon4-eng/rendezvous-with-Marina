# Марина — Симулятор свиданий

Обновлённая версия: исправлен переход между образами, добавлены полноценные развёрнутые варианты ответов и более постепенная драматургия диалогов — от знакомства и лёгкого юмора к личным темам, поэтическим и романтическим репликам.

В каждом образе 10–11 сцен, то есть 20–22 реплики в одной истории. Каждая реплика Марины имеет три полноценных варианта ответа игрока.

Работает локально на ПК и в мобильном Safari после размещения на статическом хостинге.
